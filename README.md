# Taffy Mini（塔菲）

A small archive for the exported sprite sheet of the custom ChatGPT pet **塔菲** (Taffy).

## Description

A tiny pink-haired chibi companion inspired by Yongchu Taffy, with brass goggles, starry golden eyes, and a sweet, upbeat expression.

这是一位粉色头发的 Q 版小伙伴，戴着黄铜护目镜，拥有星星般的金色眼睛，整体气质甜美活泼；灵感来自 Yongchu Taffy。
